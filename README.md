# Next.js Inventory App 📦

A full-stack inventory application built while learning modern Next.js application development, authentication, and database-backed workflows.

## ✨ Highlights

- Next.js application architecture
- Inventory management workflows
- Authentication integration
- Database-backed application concepts
- Responsive web interface

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## 🎯 Purpose

A practical project for strengthening full-stack Next.js development skills and understanding how modern web applications are structured.
